# Comment Generator for WooCommerce

This WordPress plugin allows you to generate AI-powered comments for your WooCommerce products using the Gemini API.

## Features

- Generate 5-8 authentic-looking comments with names and star ratings (4-5 stars)
- Customize the AI prompt for generating comments
- Select which comments to save
- Modern and intuitive user interface
- Works with any WooCommerce product

## Installation

1. Download the plugin zip file
2. Go to your WordPress admin panel > Plugins > Add New
3. Click "Upload Plugin" and select the downloaded zip file
4. Click "Install Now" and then "Activate Plugin"

## Requirements

- WordPress 5.0 or higher
- WooCommerce 3.0 or higher
- PHP 7.2 or higher
- Gemini API key (Get one from [Google AI Studio](https://makersuite.google.com/app/apikey))

## Setup

1. After activating the plugin, go to "Comment Generator" in the WordPress admin menu
2. Enter your Gemini API key in the Settings tab
3. Customize the default prompt if desired (or use the provided default)
4. Save settings

## Usage

1. Go to the Products tab in the Comment Generator section
2. Find the product you want to generate comments for
3. Click the "Generate Comments" button
4. Review the generated comments and modify your prompt if needed
5. Select which comments to save (all are selected by default)
6. Click "Save Selected Comments"
7. The comments will be added to your product as real customer reviews

## Custom Prompts

You can customize how comments are generated by modifying the default prompt in the Settings tab. The following placeholders are available:

- `{product_name}`: Will be replaced with the product name
- `{product_description}`: Will be replaced with the product description

Additionally, you can add specific instructions for each product when generating comments by using the "Additional Prompt" field in the generation modal.

## Troubleshooting

- If no comments appear, check your Gemini API key is valid
- If comments don't have the expected format, try updating your prompt to be more specific
- Make sure WooCommerce is active and properly configured
